# Expert System for Rock Classification using the Rete Inference Engine

This project implements a Knowledge-Based System designed to classify rocks (Igneous, Sedimentary, and Metamorphic) based on observable physical evidence. 

The system leverages the **Rete algorithm** to demonstrate complex rule evaluation through:
* **Forward Chaining:** Using an active working memory and alpha/beta networks to match evidence and infer the origin, classification, and recommended use of the rock sample.
* **Goal-Driven Pattern (Backward Chaining Simulation):** Identifying missing critical information and dynamically requesting it from the user to achieve a specific goal.

*Note: The rules and geological profiles in this repository are abstractions meant for academic and didactic purposes.*
